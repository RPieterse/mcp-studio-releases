# MCP Studio Releases

Signed release bundles for [MCP Studio](https://github.com/RPieterse/mcp-studio).

**Download & docs:** https://rpieterse.github.io/mcp-studio-releases/

This repo exists so the Tauri auto-updater (which fetches via plain HTTP, no GitHub auth) can pull updates. The source code lives in the private `mcp-studio` repo. Only the signed binaries, the updater manifest (`latest.json`), and the public download/docs site (`index.html`, `docs.html`) are published here.

Latest release: see the [releases page](https://github.com/RPieterse/mcp-studio-releases/releases).
